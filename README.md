# Web Development Projects Collection

## Overview

This repository contains a collection of beginner-friendly web development projects created using **HTML, CSS, and JavaScript**. These projects are designed to strengthen fundamental front-end development skills by implementing real-world applications with interactive user interfaces.

The repository currently includes:

* Calculator
* To-Do List
* Tribute Page
* Login Authentication System

Each project focuses on different aspects of web development such as page design, DOM manipulation, event handling, user interaction, and responsive layouts.

---

# Objectives

The main objectives of this project collection are:

* To understand the basics of HTML, CSS, and JavaScript.
* To build responsive and interactive web applications.
* To improve problem-solving skills through practical implementation.
* To learn DOM manipulation and event handling.
* To create reusable and user-friendly interfaces.
* To gain hands-on experience in front-end web development.

---

# Projects Included

## 1. Calculator

A simple calculator that performs basic arithmetic operations.

### Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear and Delete functions
* Responsive button layout
* Interactive display

---

## 2. To-Do List

A task management application for organizing daily activities.

### Features

* Add new tasks
* Edit existing tasks
* Delete tasks
* Mark tasks as completed
* Separate Pending and Completed task lists
* Display date and time of task creation

---

## 3. Tribute Page

A static webpage dedicated to an inspirational personality.

### Features

* Profile image
* Biography section
* Attractive layout
* Responsive design
* Clean typography and styling

---

## 4. Login Authentication System

A simple client-side authentication project using browser storage.

### Features

* User registration
* User login
* Authentication using localStorage
* Protected welcome page
* Logout functionality
